# String keys

Keys (English text in brackets). Translate into the languages the user wants.

- weekly: Weekly limit
- resets: Resets %s
- pace: Pace %d%%
- over: +%d pts over pace
- under: %d pts under pace
- left: Resets in %dd %dh
- updated: Updated %s
- offline: Offline %s
- nodata: No data yet. Tap to refresh
- stale: Waiting for new data
- unofficial: Unofficial app, not affiliated with Anthropic.

Do not use a translation of "Claude" as part of the app name.
